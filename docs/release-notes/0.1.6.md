# 茶室 0.1.6

## 新增

- 原生 Android 页面接入 Liquid Glass 液态玻璃：首页、加入房间、主机控制台
- 背景使用茶绿/茶金/奶油色环境光层，玻璃卡片和按钮实时采样背景，带模糊、折射、边缘高光
- 新增可复用的玻璃卡片、玻璃按钮、玻璃返回入口
- 保留 Web 聊天页完全不变；聊天仍使用原来的移动端 Web UI
- 包含 0.1.5.3 的茶室茶杯 App 图标

## 说明

- Liquid Glass 在 Android 12+ 使用模糊，Android 13+ 使用折射/镜头效果；低版本回退为半透明玻璃表面
- 本 Release 只包含更新日志，不上传 APK
- 包名 `com.vertin.teatalk`，versionCode 8，versionName 0.1.6

# 茶室 0.1.5

## 新增

- 同一 Wi-Fi 下自动发现正在开房的茶室，不再每次扫码
- 扫码加入：CameraX + ZXing
- 手动输入地址兜底
- 多设备：一个主机可多端加入，也支持多个主机房间
- 首页「开房间 / 加入房间」

## 修复

- iOS Safari 键盘弹出时聊天页被整体滚动、composer 顶到顶部
- 部分设备 WebView 聊天页只占屏幕顶部、下方空白
- CameraX Y 平面 rowStride 导致的二维码解码失败
- 发现 socket 在页面切换时未释放

## 注意

- 主机 App 需保持前台；当前无前台服务
- 自动发现需要同一 Wi-Fi 且未开启 AP 隔离；否则使用扫码/手动地址
- 局域网明文传输，仅适合可信网络
- 本 Release 只包含更新日志，不上传 APK；APK 保留在本地构建产物

# 茶室 0.1.9.1

这一版是 0.1.9 那次重设计之后的补丁版：两处明显的毛刺修掉了，另外补了两个一直缺的功能。

## 下载不再跳出 App

以前点「下载」，文件会被交给系统的下载服务，跳到通知栏里。现在 App 自己下载：

- 下载面板从底部浮出来，能看见文件名、已下载多少 / 总共多少，还有一根陶土色的进度条
- 收起来之后是一个小胶囊，浮在输入框上方，点一下就重新展开
- 下载是进程级的，**离开聊天页不会中断**；回来还能接着看进度
- Android 10 及以上存进系统「下载/茶室」，可以直接点「打开」；Android 8–9 存进 App 自己的下载目录

没有权限弹窗，也不需要存储权限。

## 首页多了「设置」

右上角一个等宽字的「设置」胶囊，里面先放外观：**跟随系统 / 浅色 / 深色**。

原生页面会立刻变；聊天页也会跟随，但已经打开的那个页面要重新进一次才会变——这一条写在了设置面板里，不藏起来。

为了让强制主题不闪，Web 端加了一个 `theme-boot.js`，在样式表之前就把主题定下来。

## 顺手修的

- **开房页太挤**：本机自检、网络地址、诊断说明全部收进默认折叠的「高级选项」，「进入聊天」上移到它上面。第一眼只剩二维码和两个按钮。
- **聊天输入栏没对齐**：输入框、＋、发送键原来不在一条基线上，现在统一到 34px，单行文字和两侧按钮齐平。
- **文件库分隔线只显示半截**：右滑按钮的色块盖住了行的下边框，改成用伪元素画在上面。

# 茶室 0.1.8

## 修复

- 主机切后台后房间掉线、通知栏点开聊天页出现 `ERR_CONNECTION_REFUSED`
- 服务器从 HostActivity 迁移到进程级 HostRuntime，前台服务负责持有生命周期
- 前台服务被杀后 `START_STICKY` 重启会重新拉起房间
- 通知点击使用 `CLEAR_TOP` 回到已有 HostActivity，不再重复创建服务器
- 新增「关闭房间」按钮：返回首页=后台继续开房，关闭房间=真正停止房间和服务

## 保留

- Material UI 与轻量 Web 样式
- 文件库、清除聊天记录、7 天保留/延期
- 茶杯 App 图标

## 说明

- 本 Release 只包含更新日志，不上传 APK
- 包名 `com.vertin.teatalk`，versionCode 10，versionName 0.1.8

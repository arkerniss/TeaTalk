# 茶室 0.1.7

## 新增

- Web 聊天页轻量液态玻璃：顶栏、输入栏、用户/菜单/文件面板、加入卡片
- 聊天页 UI 动画：环境背景漂移、消息上浮、面板/弹窗入场、发送按钮按压、新消息提示
- 主机前台服务保活：切到后台或锁屏后房间继续在线，通知栏显示「茶室正在开房」
- CPU 部分唤醒锁 + Wi-Fi 高性能锁；Android 13+ 通知权限请求
- 保留原生 Android 的 Liquid Glass 首页/加入/主机控制台
- 保留茶杯 App 图标

## 说明

- Web 使用 CSS backdrop-filter；现代 Chrome/Edge/Safari/Firefox 显示模糊玻璃，旧浏览器回退实色
- 真正的折射镜头效果仅原生 Android 13+ 可用，Web 采用轻量拟态玻璃
- 本 Release 只包含更新日志，不上传 APK
- 包名 `com.vertin.teatalk`，versionCode 9，versionName 0.1.7

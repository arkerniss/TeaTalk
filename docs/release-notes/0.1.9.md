# 茶室 0.1.9

这一版把界面整个换了一遍。设计语言叫 **Paper & Clay**——暖纸色的底、衬线标题、一处陶土色，像一张摊开的纸，而不是一块会发光的玻璃。

Web 聊天页和四个原生页面用的是同一套规矩，所以安卓、iPhone、电脑上看起来是同一间茶室。

## 变化

- 暖纸底 `#FAF8F3`（暗色 `#121110`）、白色浮起面、凹陷的输入井；分隔改用 1px 发丝线，不再靠边框和阴影
- 单一陶土强调色 `#AE5129`（暗色 `#D9784F`），取代之前的青绿 + 橙双强调色
- 品牌和标题用衬线字；时间、IP、人数、文件大小、区块标签统一用等宽字
- 消息分组：同一个人 5 分钟内连发的几条，共用一条昵称/时间头，间距收紧到 3px
- 输入区改成一个凹陷输入井 + 陶土圆形发送键，没打字时发送键置灰
- 文件图标换成扩展名徽标（TXT、PNG），不再用 emoji；文件库改为发丝线分隔的行
- 「延期 7 天」由红色改为陶土色——它是日常操作，不是危险动作
- 启动图标换色：墨黑底、纸色杯、陶土茶汤、浅陶土热气

## 暗色模式

浅色和暗色都跟着系统走，不用手动切。Web 端用 `prefers-color-scheme`，原生端用 `isSystemInDarkTheme()`；窗口主题、WebView 底色和系统栏图标颜色也会一起跟随。新增 `values-night/themes.xml`，冷启动时不再闪一下白屏。

## 性能

上一版的动效被反馈过「觉得卡」，这版做了减法：

- 去掉毛玻璃 `backdrop-filter`、渐变背景、气泡阴影
- 去掉入场编排动画，只保留颜色/边框 140ms 过渡和按下缩放
